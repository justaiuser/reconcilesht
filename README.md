# Сверка актов

Веб-приложение для бухгалтерии: сравнивает скан акта сверки в PDF с актом, выгруженным из учётной программы в Excel, и показывает расхождения по строкам и итогам.

Файлы читаются в браузере на вашем компьютере. На сервер они не отправляются.

## Что умеет

- Читает PDF, в котором страницы — изображения, без текстового слоя.
- Читает книгу Excel `.xlsx` с одной или двумя колонками: «по нашим данным» и «по данным контрагента».
- Сопоставляет документы по номеру и дате.
- Отмечает разные суммы, строки только в Excel и строки только в скане.
- Сверяет сальдо и обороты.
- Сохраняет отчёт в Excel.

Старый формат `.xls` нужно сначала сохранить как `.xlsx`.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Next.js, обычно [http://localhost:3000](http://localhost:3000).

Кнопка «Открыть пример» подставляет учебный акт ООО «Север» и ООО «Луч». В колонке контрагента на скане другие суммы по №27 и №88, нет реализации №31 и есть корректировка №5.

Проверка логики сверки:

```bash
npm test
```

## Как пользоваться

1. Выберите скан акта (PDF) и файл из программы (`.xlsx`).
2. Проверьте, что в предпросмотре Excel дата, документ и суммы стоят в своих колонках. Если нет — поправьте поля.
3. Нажмите «Сравнить». Одна страница обычно читается меньше минуты. На длинном скане компьютер может притормаживать.
4. Смотрите расхождения. Если программа сопоставила не ту колонку, переключите «Что сверять» и «Суммы».
5. При необходимости скачайте отчёт.

Лучше читаются ровные сканы от 200 dpi. Модуль распознавания русского текста уже лежит в проекте, отдельный ключ не нужен.
