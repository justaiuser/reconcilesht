# Сверка актов

Локальная программа для бухгалтеров: сравнивает акт сверки контрагента (PDF, в том числе скан) с актом из 1С (Excel `.xlsx`) и показывает совпадения, расхождения по дебету/кредиту, начальное и конечное сальдо и краткий анализ.

Если в одном скане уже две колонки («наши» и «контрагент»), Excel не обязателен — достаточно галочки «Прикрепить один файл».

Файлы обрабатываются на компьютере, где запущена программа, и в интернет не уходят. Модель Qwen (через Ollama) — запасной вариант, когда обычный OCR почти ничего не прочитал.

## Что умеет

- Читает PDF со сканами (OCR) и PDF с текстовым слоем (без OCR, если в слое есть даты и суммы).
- Читает книгу Excel `.xlsx` из 1С с одной или двумя колонками: «по нашим данным» и «по данным контрагента».
- Режим одного файла: сверяет левую колонку скана с правой. Если в PDF несколько актов подряд, каждый сравнивается отдельно.
- Сопоставляет строки по номеру и дате документа.
- Отмечает разные суммы, строки только в Excel и строки только в скане.
- Сверяет сальдо начальное/конечное и обороты.
- Даёт краткий анализ совпадений и расхождений.
- Сохраняет отчёт в Excel.

Старый формат `.xls` нужно сначала сохранить как `.xlsx`.

## Запуск у себя

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Next.js, обычно [http://localhost:3000](http://localhost:3000).

Кнопка «Открыть пример» подставляет учебный акт ООО «Север» и ООО «Луч». В колонке контрагента на скане другие суммы по №27 и №88, нет реализации №31 и есть корректировка №5.

Проверка логики сверки:

```bash
npm test
```

Сборка для постоянного запуска на одном ПК в отделе:

```bash
npm install
npm run build
npm run start:lan
```

`start:lan` слушает `0.0.0.0:3000`, чтобы другие компьютеры в сети открывали программу по IP этой машины. Для разработки с доступом из сети: `npm run dev:lan`.

## Как пользоваться

1. Выберите скан акта (PDF) и файл из 1С (`.xlsx`). Если компании уже стоят в одном скане слева и справа, включите «Прикрепить один файл» и приложите только PDF.
2. Проверьте, что в предпросмотре Excel дата, документ и суммы стоят в своих колонках. Если нет — поправьте поля.
3. Нажмите «Сравнить». Одна страница обычно читается меньше минуты. На длинном скане компьютер может притормаживать.
4. Смотрите анализ, итоги сальдо и таблицу совпадений/расхождений. При необходимости переключите «Что сверять» и «Суммы».
5. Скачайте отчёт в Excel.

Лучше читаются ровные сканы от 200 dpi. Модуль OCR русского текста уже в проекте, отдельный ключ не нужен.

## Раздача бухгалтерам в локальной сети

1. На одном компьютере отдела выполните `npm run build` и `npm run start:lan` (или `npm run dev:lan` для проверки).
2. Узнайте IPv4 этой машины (`ipconfig` в Windows, `ip a` / `hostname -I` в Linux).
3. У бухгалтеров откройте, например, `http://192.168.1.20:3000`.
4. Если страница не открывается, разрешите входящие подключения на порт 3000 в брандмауэре.

## Qwen (запасной OCR)

Модель не запускается в браузере бухгалтера. Её ставит один компьютер в отделе; остальные открывают программу по его адресу в локальной сети.

Нужны Ollama 0.12.7 или новее, около 4 ГБ свободной памяти и, лучше, видеокарта. Модель занимает около 1,9 ГБ.

```bash
ollama pull qwen3-vl:2b-instruct
npm install
npm run dev:lan
```

Ollama остаётся на `127.0.0.1:11434` и с других компьютеров не открывается. Когда модель отвечает, в окне появляется галочка «Читать через Qwen». Без галочки сначала идёт обычное чтение строк; если оно почти ничего не нашло, программа сама пробует Qwen.

Без видеокарты модель 2B читает одну страницу примерно за полторы–две с половиной минуты. Если есть видеокарта с 8 ГБ памяти, поставьте `ollama pull qwen3-vl:8b-instruct` (6,1 ГБ): она точнее, и программа сама выберет самую крупную скачанную сборку instruct.

Конкретную сборку задаёт переменная `QWEN_MODEL`. Адрес Ollama, если он не на этой же машине — `OLLAMA_HOST`. Нужна сборка instruct, а не thinking.
