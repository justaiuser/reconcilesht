# Сверка актов

Веб-приложение для бухгалтерии: сравнивает скан акта сверки в PDF с актом, выгруженным из учётной программы в Excel, и показывает расхождения по строкам и итогам. Если в одном скане уже две колонки, Excel не нужен.

Скан читается на компьютере, где запущена программа: страница режется на отдельные строки, и цифры берутся из своей строки. Файл не уходит в интернет. Модель Qwen можно включить галочкой, но она переписывает таблицу и путает похожие суммы, поэтому для сверки её лучше не использовать.

## Что умеет

- Читает PDF, в котором страницы — изображения, без текстового слоя.
- Читает книгу Excel `.xlsx` с одной или двумя колонками: «по нашим данным» и «по данным контрагента».
- По галочке «Прикрепить один файл» сверяет левую колонку скана с правой, без Excel. Если в PDF несколько актов подряд, каждый сравнивается отдельно.
- Сопоставляет документы по номеру и дате.
- Отмечает разные суммы, строки только в Excel и строки только в скане.
- Сверяет сальдо и обороты.
- Сохраняет отчёт в Excel.

Старый формат `.xls` нужно сначала сохранить как `.xlsx`.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Next.js, обычно [http://localhost:3000](http://localhost:3000).

Кнопка «Открыть пример» подставляет учебный акт ООО «Север» и ООО «Луч». В колонке контрагента на скане другие суммы по №27 и №88, нет реализации №31 и есть корректировка №5.

Проверка логики сверки:

```bash
npm test
```

## Как пользоваться

1. Выберите скан акта (PDF) и файл из программы (`.xlsx`). Если компании уже стоят в одном скане слева и справа, включите «Прикрепить один файл» и приложите только PDF.
2. Проверьте, что в предпросмотре Excel дата, документ и суммы стоят в своих колонках. Если нет — поправьте поля.
3. Нажмите «Сравнить». Одна страница обычно читается меньше минуты. На длинном скане компьютер может притормаживать.
4. Смотрите расхождения. Если программа сопоставила не ту колонку, переключите «Что сверять» и «Суммы». Для одного файла остаётся только переключатель «Суммы».
5. При необходимости скачайте отчёт.

Лучше читаются ровные сканы от 200 dpi. Модуль распознавания русского текста уже лежит в проекте, отдельный ключ не нужен.

## Qwen на мощном компьютере

Модель не запускается в браузере бухгалтера. Её ставит один компьютер в отделе, а остальные открывают программу по его адресу в локальной сети.

На этом компьютере нужны Ollama 0.12.7 или новее, около 4 ГБ свободной памяти и, лучше, видеокарта. Модель занимает около 1,9 ГБ.

```bash
ollama pull qwen3-vl:2b-instruct
npm install
npm run dev -- -H 0.0.0.0 -p 3000
```

Ollama остаётся на `127.0.0.1:11434` и с других компьютеров не открывается. Программа слушает порт 3000. Узнайте адрес компьютера в сети (в PowerShell: `ipconfig`, строка IPv4) и откройте у бухгалтеров, например, `http://192.168.1.20:3000`. Если страница не открывается, разрешите входящие подключения на порт 3000 в брандмауэре Windows.

Когда модель отвечает, в окне появляется галочка «Читать через Qwen». Она выключена: без неё программа читает каждую строку отдельно. Включайте модель только если обычное чтение не разобрало таблицу.

Без видеокарты модель 2B читает одну страницу примерно за полторы-две с половиной минуты. Если на компьютере есть видеокарта с 8 ГБ памяти, поставьте `ollama pull qwen3-vl:8b-instruct` (6,1 ГБ): она точнее, и программа сама выберет самую крупную скачанную сборку instruct.

Конкретную сборку Qwen3-VL можно задать переменной `QWEN_MODEL`. Адрес Ollama, если он не на этом же компьютере, задаётся переменной `OLLAMA_HOST`. Для чтения актов нужна сборка instruct, а не thinking.
